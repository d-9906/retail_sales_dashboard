# Retail Sales Performance Dashboard

## Project Overview

This project analyzes retail sales data using Microsoft Excel and Power BI to identify sales trends, customer behavior, regional performance, and product performance.

The project demonstrates data cleaning, dashboard creation, and business intelligence skills.

## Tools Used

- Microsoft Excel
- Power BI
- GitHub

## Dataset

Sample Superstore Sales Dataset
Records: 9,994


## Key Performance Indicators

- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Features

### Excel Dashboard

- Pivot Tables
- Pivot Charts
- Interactive Slicers
- KPI Cards

### Power BI Dashboard

- KPI Cards
- Interactive Filters
- Charts
- Business Insights

## Business Insights

- Technology generated the highest sales.
- The West region recorded the highest sales.
- Consumer customers contributed the highest profit.
- Standard Class was the most frequently used shipping mode.
- Sales increased toward the end of the year.
- A few products contributed a significant portion of total revenue.
